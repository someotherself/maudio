# Contributing

Thank you for your interest in improving maudio. Bug reports, feature requests,questions, and other feedback are very welcome.

## Before making changes

This project is not currently accepting pull requests. If you find a problem or have an idea for an improvement, please open an issue or contact me by email before doing any work on a fork.

The project is under active development, and I am closely involved in its direction and implementation. Issues and requests will be reviewed and worked on.

Even when a proposed implementation is not accepted, the problem it is trying to solve may still be valid and useful to know about. Please do report it.

## Reporting an issue or proposing a change

When possible, include:

- a clear description of the problem or proposed behavior

- a small example or steps to reproduce the issue

- the platform, Rust version, and relevant crate features

- any constraints or use cases that may affect the solution.

Thank you for helping improve maudio
